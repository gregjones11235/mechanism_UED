唯一允许差异 (carry_mode 运行时标志, 不影响 params/网络/loss/LR/Replay/optimizer):
  [GPU2 Persistent]  RMT tokens 跨128步 collector rollout 边界保留(携带更新后的tokens)，
                     仅在对应环境 true done 时重置。
  [GPU3 Reset128]    RMT tokens 在每个128步 collector rollout 边界恢复为初始(全0)，
                     但单个128步 rollout 内部正常读取/更新并参与训练；true done 也重置。

实现位点: rmt_memory_anchor.rmt_advance_tokens(carry_mode) —— 段边界处:
  persistent -> mem_tokens <- 更新后tokens ; reset128 -> mem_tokens <- 0
  两模式下 seg_buf/seg_count 都在边界复位; GTrXL memory 不受 carry_mode 影响。

断言: 无网络结构差异 / 无 loss 差异 / 无 LR 差异 / 无 Replay 系数差异 / 无 optimizer 差异。
