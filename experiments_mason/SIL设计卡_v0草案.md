# SIL 设计卡(v0 草案,周三定稿)——P1 墙的第一处方

> 2026-07-21 草案。状态:**申请立项,本周不实现**(采集半件为可选加分项,见 §7)。
> 谱系:Self-Imitation Learning(Oh et al., 2018)+ 死因地形图定向修正。

## 1. 一句话

把裸链中已被证明可行的行为(达 2 层且资源健康的轨迹片段)克隆回策略,
改数据分布而非奖励/课程——与已证伪三族严格正交。

## 2. 为什么是它(因果链,周五口径)

验尸地形图(n=1024 官方协议,7/21):74.6% 死于 1 层,且死时交战比 2.30
(边赢边死)→ 病理 = 磨损率(1 层每步伤害摄入 ~3× 0 层)× 资源
(30.6% 死者 drink=0)× 时钟,**不是接战意愿**(逐杀稠密据此已毙)。
SIL 搬运的恰是能力包:可持续交战 + 资源管理 + 下楼时机——处方对症。
达 2 层队列 +12 分溢价 = 教材已存在,只是从未被放大。

## 3. 供数:裸链槽位自采黄金库(核心设计决策)

- 训练侧划出裸链槽位(bare-chain episodes,训练种子,无脚手架任务),
  host 端 RingBuffer 收 **top-10% 回报** 轨迹;
- **筛选双维度**:①最深楼层 ≥2;②资源健康度(入 1 层时 food/drink 水位
  ≥ 阈值)——地形图新增维度,"管好水壶再下楼"本身是待克隆技能;
- **红线:严禁使用官方 held-out 评测集轨迹**(含现存 134 条)——协议
  污染即取消资格;黄金库只能来自训练分布;
- 附带收益:供数与目标同分布,"脚手架迁移风险"问号被设计消解
  (咨询包 Gemini 方案 A 修雷版)。

## 4. 损失形态:片段级 BC(三家独立合流,咨询包共识)

- **不做全轨迹克隆**:只克隆关键片段——入 1/2 层前后 N 步窗口
  (下楼决策 + 初期生存),0 层日常不进损失;
- actor-only:L_SIL = −logπ(a|s) · w,**critic 不动**(免与 GAE 打架);
- 权重 w:advantage 过滤 (R−V)⁺(原版 SIL 形态)或片段级归一化回报,
  二选一在设计卡定稿时锁死;
- 混合系数 λ_SIL 随训练退火;flag 门控 `+training.use_sil`,默认关 = 逐位 v1。

## 5. JAX/工程约束核对

- 采集在 host 侧(rollout 后过滤),无逐 env 分支;BC batch 定形
  (固定片段长 × 固定库容量,不足 zero-pad + mask);
- 显存:黄金库驻 host RAM,BC minibatch 才上卡,预算 < 1G;
- GTrXL 记忆:片段 BC 的 memory 初始化用零态 + burn-in 前缀
  (定稿时裁 burn-in 长度);
- 教师侧零改动,课程机制三层不碰。

## 6. 预注册判据 + 止损(先立此存照)

- 主判据:fork(13700 起,~17 session)离线官方分 vs 三方对照
  (placebo/rep2/A 同位);**裁决只认离线尸体**;
- 行为判据(仪表加持):SIL 臂验尸 vs 43.5 基线验尸——2 层步数
  (基线 1.0 步/env)、渴死率(基线 30.6%)、1 层摄入率,三针任一
  显著移动即"机制在动",总分未动也算机制信号;
- 预期路径:总分先跌后升合法(BC 拉离 on-policy 最优),止损线设在
  "N session 后黄金库无新增更深轨迹 且 行为三针零移动",不设在总分;
- 三段预注册:SIL 单独 → frontier-spawn 单独(依赖黄金库,出生点
  从库中深层/资源健康状态采样)→ 组合;不跳段。

## 7. 排期与可选加分项

- 周三:本卡定稿 + 周报;周五:申请立项(设计卡形态上桌);
- 实现估算:2-3 天(采集 0.5 + 损失与混合 1 + 烟测收数 1);
- **可选加分项**(周三晚裁,不预支):采集半件——裸链槽位 + RingBuffer
  只收不训,零训练风险,周五展示"库已在收货";止损:周四中午未绿即撤,
  讲稿优先。

## 8. 风险清单(诚实条款)

- 片段 BC 的 memory burn-in 若失真,克隆的是"无记忆版行为"(GTrXL
  依赖历史)——烟测必须含 burn-in 消融一针;
- 黄金库早期样本少 → 过拟合少数轨迹;库容量与去重策略定稿时锁;
- 裸链槽位挤占课程槽位 → 教师吞吐微降(r=−0.52 已证伪吞吐税,
  风险低,仍记录);
- 上界诚实度:SIL 放大已有解,不发明新解;3 层 0 条 = 3 层无教材,
  本提案的目标是把 16.4% 的 2 层到达率变成常驻能力,不承诺破 3 层
  ——破 3 层是 frontier-spawn/第三阶段的事。
