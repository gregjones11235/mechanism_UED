= 提高巩固练习的采样效率),也把"gap 可由课程机制而非模型规模弥合"从推测升为分解证据。

## 5. 诚实清单

1. **n=1**:全部结论单 seed;论文对照方 48.33 是 5-seed 均值,量纲不同,直接比较需注明;
2. **中途热修**:0.865e9 处课程图错边修正(书 = 3/4 层首箱,手工与自动抽取双漏),
   run 定性为 "2e9 with curriculum-graph hotfix";热修前后对照本身构成天然实验
   (gnomish 死零→15%,sapphire 反超);
3. **尾部崩溃**:终值取崩溃前存档;PPO 尾部破坏性更新,非机制相关;
4. **计数器序列化 bug**(env_steps / update 计数 / ckpt 编号同源未存档):造成两段编号
   碰撞与中段离线不可复评;收工必修项,已立案;
5. 分解恒等式残差 ~1 分(加权技能和 44.35 vs 实测 43.47):episode 内成就一次性计分与
   期望近似的固有偏差,家族排序结论不受影响;
6. 步数不对称(§3)与 235B 终点缺席:两处待 Alec 数据闭合。
