## 5. 诚实清单

1. **n=1**:全部结论单 seed;论文对照方 48.33 是 5-seed 均值,量纲不同——且现有方差参照:
   Alec 同管线单 seed 复现终点 46.74 vs 论文 5-seed 48.33,单 seed 波动 ~1.6 分;
2. **C-1 在 3e8 消融中哑火**:check_compilation 返回 str(e) 无异常类前缀,分类正则要求前缀
   → hallucination-class 0/45。已修(prefix-optional + H4 缺 import 类,62 tests);C-1 维持
   "已实现 + 离线验证"定位,在体疗效未测;
3. **v2 消融的 regime 混杂**:R3 豁免只对已掌握前置生效,0-3e8 冷启动窗口 mastered 集小,
   豁免几乎无开火机会——判据预注册于此窗口,裁决(不过线)有效,但"晚期 regime 下豁免
   是否有效"未测(resume-A/B 为周五备选项);
4. **中途热修**:0.865e9 处课程图错边修正(书 = 3/4 层首箱,手工与自动抽取双漏),
   run 定性为 "2e9 with curriculum-graph hotfix";热修前后对照本身构成天然实验
   (gnomish 死零→15%,sapphire 反超);
5. **尾部崩溃**:终值取崩溃前存档;PPO 尾部破坏性更新,非机制相关;
6. **计数器序列化 bug**(env_steps / update 计数 / ckpt 编号同源未存档):造成两段编号
   碰撞与中段离线不可复评;收工必修项,已立案;
7. 分解恒等式残差 ~1 分(加权技能和 44.35 vs 实测 43.47):episode 内成就一次性计分与
   期望近似的固有偏差,家族排序结论不受影响;
8. 步数不对称(§3 中段版):以终点对终点分解为准表。

## 6. 结论与待决(2026-07-15 更新:teacher 侧关账)

**Teacher 侧正式收摊,有双重消融背书**:R3 豁免在冷启动(3e8 消融)与晚期 regime
(fork A/B,从 1.74e9 分叉同起点对照)双双证伪(详见 forkB_裁决与threshold04预判.md);
崩溃在两臂同 schedule 位复现(系统性病理,非偶发);官方 eval 单点噪声实测 ±1.5。
3e8 消融按预注册止损线不过线(五点对表 13.7/18.3/29.8/32.6/33.1 vs 主跑 12.5/25.4/31.0/
32.3/~34;gnomish 0)。"**~43.5 即本框架 teacher 侧极限**"进入论文结论。

**Gap 的三段式解剖(论文叙事框架)**:
- 43.5 → 46.7:同族巩固度(iron 线占半),课程可干预但本框架内已到边际;
- 46.7 → 48.3:单 seed 与 5-seed 均值的方差量纲(实测参照 ~1.6 分);
- 48.3 以上:四方共享的 student 侧探索墙(sewers 前全员趴零)。
