## 4. 机制侧的确证结论(这些全部站得住,与总分归零无关)

1. **门卫楼层条款饿死二层簇**:longStack 中 24/27 个入训怪关卡被 LLM 修复从 floor 2 改写到 floor 0(code 级 AST 审计);gateOff/repairF/surgical 三个方向的干预全部恢复该簇。
2. **调度器锁定真实存在但非绑定**:真图 + 阈值 0.3 下 27 个技能永久不可调度(gateOff 全程零点名验证),而二层簇仍恢复 ⇒ 锁不是那道墙。
3. **shuf 的机制 = 转向被拆掉九成**:耦合度(新关卡命中当期目标)longStack **60.0%** vs shuf **6.3%**;shuf 全程只出现 12 个唯一技能、换届 5 次。**"打乱没有改变转向方向,它把转向有效性从 60% 砍到 6%。"**
4. **回路税**:门卫其余修复剥净 premark/inventory 补贴(premark 中位 surgical 0 / gateOff 1 / base15 3)→ 任务级 SR 归零 → 全 D → 零重放 → 剂量压到 30 个关卡;**而远端仍全额响** ⇒ 训练难度与迁移脱钩;"体量税延迟收益,不阻断收益"。
5. **广度换深度是重放池的内生权衡**:三条完全不同的解锁路径付**同额** floor0 代价(−54.0 / −69.0 / −54.9 pp)。
6. **scaffold 依赖**(前半季):任务级 scaffolding 的成功指标与课程级结果反相关(五重互锁证据)。
7. **深度墙**:五臂 22 项共同全零 + 全谱系佐证(原论文 Fig19/34、UED 家族、DiCode 系);破零两项为 0.10–0.13% 痕量。

## 7. 现行结论与措辞纪律(PPT 直接用)

### 7.1 单一故事(v4)
> **LLM 写的课程到底买到了什么?** 逐层拆解后的回答:**买不到 return**(整个约束栈相对同供给的基线净值 +0.03,三个预算点上均≈0);**买到的是一张可计价的机制账单**——楼层条款饿死二层簇、调度器把课程栽培成 75% 单一化、回路税压低繁殖剂量,每一笔都有干预级证据;而基线管线的一个供给旋钮(parents 2→15)比整个栈更值钱。

### 7.2 四条可以上台的硬句子
1. "打乱没有改变转向的方向,它把转向有效性从 **60% 砍到 6%** —— shufGraph 是一台失去方向盘的涌现引擎跑出的成绩。"
2. "真图的门卫把 **24/27** 个二层怪关卡改写回了地表;三个方向的干预都把它们救了回来。"
3. "锁是真的,但不是那道墙 —— 门卫关掉后,调度器**一次都没点名过**那三只怪,二层簇照样全额恢复。"
4. "**一个基线旋钮 > 整个机制栈。**"

### 7.3 措辞纪律(必须遵守)
- 总分一律 **descriptive**:同种子 n=1,种子 sd≈1.0;认证带 8/17 才有。
- 双窗口并报(全10 / 末3);surgical 与 base15 在 2e9 截断时**仍在上升**(截断相位 caveat)。
- **不写"打乱更好"**;shuf 是不可推荐配置(耦合 6.3% 的意外)。
- "知识不承重 / 机器承重"**已退役**,任何版本都不要复活。
- api-ref 披露必须出现在任何跨轮定量对照的脚注里。
- base15 / surgical / gateOff / repairF 均为**单臂 n=1**,认证在飞行中。
