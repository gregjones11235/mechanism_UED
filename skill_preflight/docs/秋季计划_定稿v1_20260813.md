## 2. 臂候选(全部单变量、全部预注册)

### 2.1 【一号候选】`base15 + preflight` —— 稳定性的价格

- **配置**:base15 全套 + `use_preflight=true`,**不加**调度器、不加门卫。单变量。
- **机制**:preflight 过滤不可学关卡 ⇒ 直接的方差抑制器;同时它是唯一"不改变转向、只改变准入"的栈部件。
- **主终点(中介量)**:臂内去趋势 ckpt 抖动、每 session 训练批的任务 SR 分布宽度、被拒关卡的 SR 分布;**总分 descriptive**。
- **预注册双向预测**:
  - 抖动显著低于 base15 且广度(食谱分散度、二层簇)保持 ⇒ **"稳定性可以单独买到,不必付转向的税"**;
  - 抖动不降 ⇒ 方差来源不在关卡可学性,而在别处(生成内容本身),preflight 的价值主张作废。
- **触发条件**:①命中即为第一臂;未命中则排在 capacity 之后作为秋季第二臂。
- **成本**:62h × 1 卡(理想再加 1 颗种子)。

### 2.2 【二号候选】池子吞吐剂量臂(`active_task_capacity`)

- **实测依据**:capacity=100 **全程约 85% 满载**(surgical 第 26 次采样、base15 第 22 次采样即贴顶);全季约 750 个任务竞争 100 个位子,淘汰 650。
- **淘汰规则(已考古)**:`attempt_to_activate_task` 对最低分活跃任务做 compare-and-swap,分数 = `sr(1−sr)`。**该函数在 sr=0 与 sr=1 处同为零 ⇒ "太难"与"已掌握"不可区分。**
- **设计**:capacity 100 → 200 → 300 剂量梯度(或按算力取两档);**A 类三项(capacity / num_generation_tasks / evolution_interval)同属一轴,只开一个剂量臂,不开三个。**
- **主终点(中介量)**:每任务平均重放次数、食谱 f0–f3 分散度、被淘汰任务的分数分布、floor0 技能簇恢复度;**总分 descriptive**。
- **预注册双向预测**:
  - **缓解侧**:门槛降低 → 边缘任务留存 → 多样性上升 → floor0 代价缓解、零和松动;
  - **稀释侧**:池子变大但每 session 仍只抽 15 ⇒ 每任务重放摊薄(15/300 而非 15/100),什么都没买到。
- **意义**:这是对我们自己"广度换深度=重放池预算内生零和"结论的**直接检验**,不是旋钮试错。

### 2.3 【三号候选】pivot `sr(1−sr)` 加权

- **配置**:底座 **base15**(在推荐配置上直接兑现,且不与门卫叠加),生成侧 pivot 选择从新颖度/均匀改为 learnability 加权。一行改动。
- **主终点**:生成侧对 B/C 带(中等 SR)的命中率;总分 descriptive。
- **风险标注**:若它改善 base15,推荐配置将**领先于认证带** ⇒ 论文写"改进方向,n=1,认证 pending"。
- **优点**:排期最友好(改动最小),8/17 点火可在 8/19–20 落地,赶得上 paper 窗口。

### 2.4 【外部算力】教师梯度 —— 最值钱的未测轴

- **问题**:全季所有臂用同一个 qwen2.5-coder:14b,**教师能力轴从未变过** ⇒ "上限被模型能力锁住"这一主张零证据。
- **设计**:同管线换教师(14B / 30B / 更大),其余全冻——即 DiCode 自己的消融轴。
- **约束**:单卡放不下 30B + JAX,无 API ⇒ **本线不可及**,归 future work;可作跨线协作提给有算力的一方。

### 2.5 【跨线协作】parents 交叉检验

- **假说**:DiCode 默认值为 235B 精调 ⇒ 我们为 14B 调的参数在 235B 上效应**衰减**(注意:我们的机制**不预测反转**,只预测衰减)。
- **做法**:把 `additional_num_parents=15` 递给 235B 那条线,在他们配置上跑一次。
- **可写的重句(今天就成立)**:他们的 30B→80B = +1.50;我们在 14B 上动一个他们从未调过的默认值 = **+1.90**。
- **定位纪律**:写成"识别并量化一个 confound",**不写"推翻他们的结论"**;详见 §4.3。

### 2.6 已取消 / 已出局(附理由,防复活)

| 项 | 理由 |
|---|---|
| batch-fix 臂 | 实测缺口 5%(注入周期 8.7%),非考古估计的 25–40% ⇒ 预期收益在噪声下;bug 顺手修(hygiene),不立臂 |
| 深味槽 | 可测产物全零(f3+ eval +0.07pp);重返条件 = 提出预测非零中介量的机制 |
| "复刻 shuf 配比" | 池内配比挪动是再分配非增量(shuf 与 base15 同总分、反向组合);三个 f1 点来自异质机制,穿峰调参 = 表型拟合 |
| 二合一臂 | 预注册扳机("近端响远端不响")未触发 |
| 起始分布剂量臂 / 自由槽 | 降为论文 future work(不占卡);理论 = 起始状态分布假设,主终点为中介量峰形 |

### 3.2 秋季

1. `base15 + preflight`(若未在 8 月跑)
2. capacity 剂量臂(两到三档 + 中介量)
3. pivot(若未在 8 月跑)
4. 跨线:parents 交叉检验、教师梯度(视算力)

### 3.3 纪律(每臂适用)

- **单变量**;A 类同轴项只开一个剂量臂;
- **判据、判读带、分支读法一律冻结在数据之前**;
- **主终点是中介量,总分一律 descriptive**;
- **n=1 下扫 k 个旋钮 ≈ 制造 k 个假阳性**(种子 sd≈1.0)⇒ 新候选须同时具备:≥2σ 先验 + 机制解释 + 可补种子;
- **零算力前置检查制度**:代码考古只给假设与方向,**量级必须实测**(batch-fix 臂即由此十分钟测量取消,省六天);
- **per-skill 主张必须配误差棒**(去趋势 ckpt sd ÷ √4):<2σ 写"未定",2–3σ 写"suggestive",不写"过/不过"。

## 4. 秋季要守的三条措辞纪律

### 4.1 关于"上限"
可写:"跨教师侧机制 / 学生侧奖励 / 供给三类共十二个预注册干预,无一把 2e9 return 推出种子带。"
**不可写**:"上限被模型能力锁住"——教师轴从未变过,零证据。反证三条:parents 是全季最大杠杆且不在教师轴上;深度墙是全谱系事实(235B 自身仅 21.5% of max);教师侧改进被供给过剩吸收。

### 4.2 关于泛化
- Craftax 私有:具体分数、二层簇故事、深度墙位置、那张 67 节点图 ⇒ 直接进 limitations;
- 机制级、跨系统可复现:不可达门锁死机制、**LLM 验证/修复环路篡改生成内容**、重放池零和、供给宽度支配课程转向;
- 现成的跨系统证据:TG-MES 线(不同教师、不同代码库、不同评测口径)与本线**独立收敛四处**(噪声阶梯三层框架、per-skill 为主透镜、小模型教师 API 幻觉族、判据先于结果)。

### 4.3 关于 DiCode
- **砸的是 teacher-scaling 的解释,不是他们的数字**:那条梯子是在"为最大模型调好的配置"下测的 = 标准的调参偏向批评被用到 scaling 轴上;
- **不砸 LLM-supported UED 的基底**——恰恰相反:base15(14B 写课程)45.02 vs 非 LLM 谱系 1e9 最好的 PPO-RNN 34.6 ⇒ **LLM 写课程本身值 10+ 分**;
- **准确说法 = 功劳重新分配**:功劳在"有 LLM 写 code-level 任务" + "供给/池子配置",不在"教师更大"或"机制更多";
- 只能写弱版本:"梯子的 14B→80B 段可能是调参产物;235B 那一跳未被解释掉"(base15 45.02/45.83 = 他们的 80B 点,距 235B 48.55 仍差 2.7–3.5)。
