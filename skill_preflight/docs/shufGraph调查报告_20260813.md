**Skill-Preflight UED · Mason · 2026-08-13**

## 0. 一页摘要

shufGraph 是一个**对照臂**:把先验技能图的前置边随机打乱,预期机制失效、分数下降。它却拿到了当时全场最高的 45.66(末3 45.85)。本调查用四个单变量臂和一系列档案分析回答了三个问题:

1. **它为什么高?** 不是打乱"找到了更好的课程",而是打乱**同时打空了栈的两个转向器**(调度器目标 + 门卫判据),让底层生成器的涌现动力学透了出来。真图栈的门卫有一条"楼层条款",一直在把二层怪关卡改写回地表、饿死二层技能簇——这是干预级证据链闭合的机制结论。
2. **修好栈能追上它吗?** 外科修复(只摘那一条条款)让二层簇全额恢复(条件命中 0.80,与 shuf 同档),机制判决"响"。但——
3. **栈本身值多少?** 最后一个臂 base15(基线管线 + 仅把 parents 2→15,无任何 skill_preflight)**踩着 shuf 落地**(末3 45.83 vs 45.85,差 0.026),二层簇亦不逊于 shuf(mines 稳健更高 3.4σ;bat/archer 同向但为边缘,见附录 A.6)。**整个"盲栈"(preflight + 噪声调度 + 盲门卫)的总分净值 ≈ 0;parents 一个旋钮的贡献(+1.9~2.5)超过整个机制栈(+1.6)。**

**季终结论:在本预算与环境下,涌现引擎全胜;约束栈的总分净值是幻觉,但其机制层代价有完整的因果解剖(逐条款价目表)。** 推荐配置 = base15,认证种子 s2/s3 在跑(8/16 落地)。

## 1. 起点:意外与两个混淆

| 臂 | 全10 / 末3 | 说明 |
|---|---|---|
| longStack(真图栈,S1) | 44.73 / 45.13 | 主配置 |
| **shufGraph(打乱图)** | **45.66 / 45.85** | 对照臂,意外最高 |
| base2e9(基线,parents=2) | 43.12 / 43.35 | 无 skill_preflight |

初步档案考古发现 shuf 与真图臂的差不在"图的好坏",而在**图的两个消费者**:

- **调度器**:hardest-first 在打乱图上选出的目标 99.8% 落在 floor 4–8 的深层成就(前置被洗成浅层技能→永远可选、永远清不掉);
- **门卫(ScaffoldGate)**:R3 判据"起始楼层若替代未掌握前置即违规"在真图下把怪关卡改写回地表——longStack 中 **24/27 个入训怪关卡被 LLM 修复从 floor 2 改写到 floor 0**(desc 仍写二层,code 已是地表;code 级 AST 审计发现);打乱图下该判据失明,二层关卡存活。

## 2. 第一轮解离实验(8/10 判决)

设计:两个单变量臂,把两个通道拆开——**gateOff**(真图 + 门卫整个关闭)与 **repairF**(改三条边使怪前置=dungeon,门卫豁免定向打开)。判据(八项绝对阈值 + 条件命中带)全部预注册。

**结果:八项阈值全过,条件命中率整段迁移到"门卫失效档"。**

| 条件命中(怪/进矿) | warrior | archer | bat |
|---|---|---|---|
| longStack(门卫开) | 0.44 | 0.03 | 0.09 |
| gateOff | **0.79** | 0.24 | **0.72** |
| repairF | 0.73 | 0.26 | 0.30 |
| shuf / base2e9 | 0.79 / 0.79 | 0.58 / 0.40 | 0.79 / 0.74 |

隔离证据:gateOff 全程 151 次调度**零点名**三只怪 + 门卫 0 行;repairF 129/151 次点名 + 门卫 76 行 + 修复图指纹——解离拉满。code 级漏斗:gateOff 561 个怪关卡(29.5%)、95% 站在二层、零改写。

附带发现:**定向解锁的自我干扰**——repairF 的 dungeon(它自己豁免的钥匙)比 gateOff 晚 ~6 session 跨线(wandb eval 曲线 + 改写停止时序双仪器互证),因为怪目标提前占槽挤掉了 dungeon 练习。

**交易结论**:floor0 代价三臂同额(−54.0/−69.0/−54.9 pp)⇒ 广度换深度是**重放池竞争的内生权衡**,与解锁方式无关。

## 3. shuf 的成分拆解(档案与日志全倒)

**3.1 课程表**:shuf 全程 151 次调度只出现 **12 个唯一技能、换届 5 次、非深层点名 0 次**(longStack:20 技能/22 换届/真实进阶序列)——静态噪声,无任何时序智慧。

**3.2 耦合度**(新生成关卡命中当期目标的比例):**longStack 60.0% vs shuf 6.3%**。打乱不是改变转向方向,是**拆掉了九成转向**;94% 的生成回落到生成器自身先验。深层内容为恒定漏流(57/54/66 每 50-session,平)。

> 一句话版:**"打乱没有改变转向的方向,它把转向有效性从 60% 砍到 6%——shufGraph 是一台失去方向盘的涌现引擎跑出的成绩。"**(同时回答 lucky-permutation 质疑与"为何不推荐 shuf")

**3.3 训练食谱**(入训关卡按 code 起始楼层、槽位加权):

| f0 / f1 / f2 / f3+ (%) | | 
|---|---|
| shufGraph | 15.9 / 25.8 / 49.9 / 8.3 |
| longStack | 16.3 / 7.4 / **75.8** / 0.6 |
| gateOff | 8.9 / 12.0 / **75.4** / 3.8 |
| repairF | 7.2 / 46.2 / 46.4 / 0.2 |
| base2e9 | 19.2 / 24.0 / 54.7 / 2.1 |
| base15(第二轮) | 14.7 / 55.6 / 27.7 / 2.0 |

两个倒挂:①gateOff 二层食谱多于 shuf 而二层收获更少 ⇒ 残差在**多样性**不在体量;②repairF floor1 食谱高达 46.2% 而 floor1 eval 为负 ⇒ **one-step scaffold 的放置跟着图走**(改前置=改放置)。

**3.4 api-ref 混淆(诚实披露)**:8/8 pod 重建时环境变量 `DICODE_API_REF` 丢失,gateOff/repairF 与老臂 prompt 相差 3133 字符。已测量其通道:总错误率两族交错(ON 104–123 vs OFF 103/131),真实功能=kwarg 错误减半,但被供给过剩吸收(每周期编译 18–20 只用 10)⇒ 对训练的影响上界≈0。第二轮两臂已改 ON 对齐。措辞:机制结论 pattern-robust;新旧定量对照带 prompt-content caveat。

## 4. 第二轮:外科修复 + 盲栈假说(8/13 判决)

**4.1 surgical(真图栈,只摘楼层条款)**:8 行补丁 + 行为电池 + 6 项回归测试;隔离 = 76 个门卫周期全带 `R3-floor OFF` 标记(76==76)。

- **判决:响**——四阈值全过,条件命中 w **0.80** / bat 0.60(判据:w/bat 两项>0.5)。
- 总分 44.86 / **46.47**(末3 为全季最高单窗口),末段三连升 46.00→46.50→46.92,**截断时仍在上升**;末3 窗口 mines 24.35(首破 20% 墙)。
- **回路税**:门卫其余修复剥净 premark/inventory 补贴(premark 中位 0 vs gateOff 1 / base15 3)→ 任务级 SR 归零 → 全 D → 零重放 → 入训剂量仅 30——**而远端全额响**。训练难度与 held-out 迁移脱钩的最极端实例;"体量税延迟收益,不阻断收益"。
- surgical−gateOff(门卫其余功能的价格):−0.20/+1.14,**检测不到**。

**4.2 base15(基线 + parents 2→15,无任何 skill_preflight)**——预注册假说(Mason):shuf ≈ base15 + preflight + 噪声调度 + 盲门卫;base15 vs shuf 构成**单块对照**(同 parents、同 api-ref,唯一差=整个盲栈)。

三格带判决(末3,冻结):**shuf 档**。

| | 全10 / 末3 | mines | warrior | archer | bat | 条件命中 |
|---|---|---|---|---|---|---|
| base15 | 45.02 / **45.83** | **23.19** | **19.01** | **12.45** | **18.25** | .82/.54/.79 |
| shufGraph | 45.66 / 45.85 | 19.06 | 14.97 | 11.00 | 15.05 | .79/.58/.79 |

- **shuf − base15 = +0.03(末3)**:盲栈(含"筛垃圾"的 preflight)总分净值 ≈ 零。
- base15 二层簇**全季最强,全10 窗口即破 20% 墙**;对 shuf 的比较:mines +4.13(3.4σ,稳健),bat +3.20 / archer +1.46(2.1–2.7σ,同向但边缘,见附录 A.6);怪经济无人转向自发繁殖(207 关卡/85.9% 二层/A×20+B×18)。
- **梯子倒挂**:parents 一个旋钮 = +1.9~2.5,超过整个机制栈的 +1.6。
- 铁链:强形式("基线造不出铁")死——pickaxe 44.7 ≈ gateOff、sword 55、collect_iron 75.5 全部自发;弱形式存活:调度器买铁链顶端(armour +10、pickaxe +8.6,longStack 对 base15)。
- **时间维度**(应质疑补测):半程(s76)截面 base15 反超(40.49 vs 39.90);跨 44.5 线 shuf 仅早 ~13 session(轨迹噪声量级)⇒ 盲栈在**半程、终点、全程曲线三个测量点上净值均≈0**,无"加速器"价值。
- 组合指纹:同总分、反向组合(shuf f1+14/f2+44;base15 f1−18/f2+57)——盲栈唯一残效=组合再平衡。f1 食谱→f1 eval 呈非单调(26%→+14 / 46%→−14 / 56%→−18),但三点来自异质机制,**只作剂量实验的动机,不作可调参的曲线**。

## 5. 季终结论

1. **机制层(干预证据,全部保留)**:真图栈的门卫楼层条款饿死二层簇(解离 + 外科修复双向证明);调度器把课程栽培成 75% 二层单一化并锁死 frontier;修复是可行的且已"响"。
2. **价值层**:栈的总分净值在 parents 配平后 ≈ 0(三差定价:parents +1.9~2.5 / 盲栈 +0.03 / 真图转向对盲栈 −0.2~0);唯一存活的正贡献 = armour 顶端 ~+10(单技能)。
3. **shufGraph 的定性**:不是更好的课程,是**意外解除两层压制后的涌现基线**——它的全部"秘密"已拆解为:生成器先验食谱(94% 脱钩份额)+ 恒定深层漏流(6% 耦合残余,测得回报≈0)。
4. **推荐配置 = base15**;认证种子 s2/s3 在跑(8/16 落地,8/17 出认证带)。surgical/gateOff 转为机制臂(回答"转向为何收税")。

**统一 caveats**:总分全部 descriptive(同种子 n=1,种子 sd≈1.0,认证带 8/17 补);全10 与末3 双窗口并报;2e9 截断时 surgical/base15 均在上升(截断相位 caveat);api-ref 披露见 §3.4。

## 6. 秋季议程(8/13 判决 + 供给赤字实测后定稿)

排序标准由"证据谱系"改为"预期收益":零和证据(shuf 与 base15 同总分、反向组合)表明**池内配比挪动的预期总分收益 ≈ 0**;池子扩容曾是唯一有正预期总分的已知杠杆——但该杠杆的剂量已被实测证伪(见下)。

- **批量短缺修复臂:取消(前置检查判定)。** 病理本身确认存在且为栈专属(缺口只出现在注入新任务的周期,Hold 周期 73/75 满额 = "剪枝后 backfill 不重算"的指纹),但**实测缺口仅 5.0%(注入周期 8.7%),而非代码考古估计的 25–40%**(那是最坏情形推算,从未测量)。5% 的供给增量对总分的期望效应在种子噪声(sd≈1.0)之下,一张卡换一个读不出的数,不值。bug 本身在秋季搭环境时顺手修(hygiene),不单独立臂。详见附录 A.5。
  - **副产品(直接进论文)**:审稿人可能的反驳"你们的栈全程池子饥饿,该比较不公平"现在由一张测量表回答——栈的供给赤字对基线是 **5% vs 1%**(约 4pp 槽位),而 base15 领先栈 +1.8~1.9 分,量级不相称。
- **剩余第一阶段候选**:pivot sr(1−sr) 加权(把涌现判据还给生成侧,一行改动)——**底座 = base15**(在推荐配置上直接兑现,不与门卫叠加),单变量。注意认证失配:若它改善 base15,推荐配置将领先于认证带,论文写法 = "改进方向,n=1,认证 pending"。
- **Future work(进论文,不占卡)**:起始状态分布剂量臂(底座 base15、单旋钮放置采样、中介量峰形)、自由槽(支撑集恢复)、深味槽维持出局(可测产物全零,重返条件 = 非零中介量预测)。
- 配比类实验排后的机制理由(非仅预期为零):**池子大小会改变权衡结构本身**——在饥饿池里测出的配比曲线对修复后的池子没有外推价值;先扩容、后测配比才是正确的实验次序。

> 方法论注记:本节的臂取消是"零算力前置检查"制度的直接产出——代码考古只提供假设与方向,量级必须实测。两份现成日志的十分钟测量,替换掉了一个六天的实验,并把它原本要防守的反驳变成了一行可引用的数字。

## 7. 可复现性
